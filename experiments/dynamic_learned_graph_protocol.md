# 后续第 3、4 组实验设计建议（只读代码审计，尚未实施或运行）

依据本地代码审计制定；以下属于工程假设，不是已证实的论文结论。每组单独从固定的四状态参考配置出发：CE4、conditional weight=1、union Brier weight=0、hidden_dim=256、4 头、3 GCN + 2 GAT，保留理论晚融合与原图。不能根据外层测试的宽度胜者自动更换底座，也不能自动累加第 2、3 组的胜出模块。

## 代码事实

- `graph_transform/data/graph_builder.py:177`：distance 分支的历史正弦启发式在 max_distance=6 时等效为残基之间 |i-j|≤5 的双向边。d=1 的边类型为 1，d=2..5 为 2；不是空间距离图。保留这一等效语义，不在动态边实验中顺手删除 0.2sin 或新增 d=6。
- `graph_builder.py:309`：每个残基与全局节点双向连接，边类型 4、距离桶 0。当前构图没有显式自环，节点残差路径保留自身信息。
- `graph_transform/models/gcn_layers.py`：GCN 的 edge_transform(edge_features) 产生逐通道 sigmoid 门，边参与度归一化与消息缩放。
- `graph_transform/models/attention_layers.py`：GAT 根据当前节点学习已有边的注意力，并使用 edge_features 产生 attention bias 和 message gate。因此当前并不是“边完全固定不学习”；固定的是允许通信的连接集合，以及跨层不更新的边状态。
- `graph_transform/models/graph_transformer.py:745,845,867`：EdgeEncoder 仅计算一次 edge_features，三层 GCN、两层 GAT 使用同一边状态。
- `graph_transformer.py:823`：预测头所用 e_ij 在传播前取出并缓存。后续即使重新赋值 edge_features，缓存的 e_ij 也不会自动更新；应明确测试的是消息传递还是同时改变最终预测头。

## 第 3 组：在固定拓扑上测试动态边状态

建议三臂，共 15 次训练。所有臂的 edge_index、边数、主链/全局边、头中的原始 e0、理论特征路径保持一致。

| 臂 | 传播中的边状态 | 回答的问题 |
|---|---|---|
| S0 参考 | 每层都用 EdgeEncoder 的 e0 | 原来模型 |
| S1 同参数上下文对照 | 每层更新边，但端点上下文始终用传播前的 h0 | 增加边非线性与容量本身是否有效 |
| D 当前上下文动态边 | 每层更新边，端点上下文使用该层输入 h_l | 当前节点状态反馈给边，是否在 S1 之上进一步有效 |

共享一个轻量更新器，避免每层新增一套大 MLP：

`delta_e = MLP(concat(h_src, h_dst, e))`，输入 3H，瓶颈 H/2，输出 H；`e_next = e + delta_e`，必要时在 MLP 输入内部规范化而不对 e 残差整体强制 LayerNorm。S1 与 D 架构、初始化、参数量、更新次数完全相同，仅 h0/h_l 的选择不同。按有向边顺序使用 src/dst，不擅自合并方向。

每个消息层前更新一次边状态，共 5 次；第一层时 h_l=h0，两臂首次更新应严格相同。更新范围包括原图所有边（含全局边）；不添加自环，不修改全局节点通信次数。MLP 最后一层可零初始化，使实验起点与 S0 的传播完全一致；预检确认第一步梯度能到达末层、后续能到达前层。新增模块初始化独立保存 RNG，避免让旧节点/边编码器、主干、头的初始化发生无意变化。

主比较 D−S1 用来检验动态反馈；D−S0 用来检验整体实用收益。S1−S0 只说明边侧新增容量/计算或基于 h0 的边重编码有效，不足以声称“动态更新有效”。三臂最终预测头均继续使用 e0，使收益只能经消息传播到 h。若未来另测 head 使用 e_last，应独立加臂，不在本组暗中混入。

必要 pod 预检：static 关闭时输出和旧 checkpoint 兼容；零初始化更新器输出与 S0 一致；S1/D 第一次边更新一致；扰动后层端点时 D 边状态改变而 S1 不变；edge_index/边数不变；边状态及梯度有限；混合长度 packed batch 不跨图；L=1、L=2、全局边、空键情况不报错；padding 的输入值变化不改变有效键输出。

报告新增：共享更新器参数量、实际耗时/显存、各层 e_l−e0 范数、GCN/GAT gate 饱和比例。范数接近零可提示更新器未被利用；大幅变化伴随性能下降可提示噪声放大，但都不能单独证明生物学结论。

## 第 4 组：固定位置图与学习连接图

本组独立回到固定参考底座，不启用第 3 组动态边。现有 GAT 只能在已有边集合内学习权重，不能让 d≥6 的残基直接新增连接；只有候选连接集合/选择掩码能改变，才称为学习图拓扑。

建议三臂，共 15 次训练：

| 臂 | 非主链残基连接 | 边权评分器 |
|---|---|---|
| G0 原参考 | 原位置规则 d=2..5 | 原 GCN/GAT 机制 |
| G1 固定拓扑容量对照 | 仍是原位置规则 d=2..5 | 新增可学习成对评分器，只改变保留边的门控 |
| G2 学习拓扑 | 在所有有效非相邻残基对中选择固定数量 | 与 G1 相同的成对评分器、门控机制和参数量 |

始终保留所有双向主链相邻边，以及所有双向残基—全局边；它们的新增选择门恒为 1。保持无显式自环。候选集合仅包含同一条真实序列内、i<j、|i-j|≥2 的残基对，排除 padding 和全局节点。全局节点位置必须取 L，而不是固定 32。

### 预算与选择

对每条长度为 L 的序列，将原图 d=2..5 的无向残基对数量记为 M(L)。G1 精确保留原来的 M(L) 对；G2 精确选择 M(L) 对并为每对加入两个方向。因此所有臂每条序列的有效边数与原图相同，不能把更多边的收益误记成学习拓扑的收益。短序列原图已覆盖所有候选对时，不会有拓扑改变，报告应说明并按长度作描述性分层。

评分器仅使用传播前的 h0（已包含合法的序列和条件输入），一个共享低秩/小 MLP 产生对称分数 s_ij=s_ji。每次 forward 只选择一次拓扑，五层复用；这样本组只测“学习连接”而不同时测试跨层动态图。G1/G2 使用相同 scorer 和额外 sigmoid 门控，G1 中 scorer 也真实参与预测，避免用闲置参数伪装容量配对。

可以使用 hard top-M 的前向加连续松弛的 straight-through 反向，训练和推理前向都使用相同 hard 掩码及预算。该反向是有偏近似，必须在报告注明。若使用 budgeted sigmoid 松弛，温度、预算 M(L)、阈值求解方式在训练前固定，不能用外层测试调参。应预检未选择对能够通过松弛获得 selector 梯度，而不是只对已选对训练评分。分数相等使用固定 pair-index 次序稳定排序，不引入随机或新的正弦项。

全候选载体长度最多 32，可在 pod 小规模预检计算是否可接受；有效硬边预算匹配不代表 FLOPs 或显存严格匹配，必须实测报告。对 GCN，新增 gate 要参与实际消息与度归一化；对 GAT，零 gate 必须使其不进入有效 softmax 分母。不能只把被删边的 message 乘零却仍让其参加 softmax，或仅 mask edge_attr。为保留 selector 梯度，可以在候选载体上实现有权归一化；G1/G2 共用同一实现。

### 距离与边类型

不能把新 d≥6 边一律夹成原“距离 6”却声称物理距离已建模。主实验可统一为精确的序列相对距离桶 0..31（global=0，residue 使用 |i-j|）并对 G1/G2 一起使用；d≥2 非主链统一为非局部残基边类型，方向仍成对。为保持 G0 参考可解释，应保证新 carrier 在固定掩码时，d≤5 使用与旧模型完全一致的边编码；新增距离行独立初始化，旧桶行拷贝相同。当前 `EdgeEncoder` 的表长直接等于 `config.max_distance+1`，必须把新“距离桶容量”与原“建图半径”配置解耦，不能简单把 max_distance 从 6 改成 31 导致 G1 也变成全连接。新增长距离桶在 G1 不会得到使用，这属于拓扑扩展必要的伴随变化，须在报告列明。可另用规范化距离连续编码做后续独立验证，但不能在本组换掉旧距离编码并同时声称纯拓扑归因。

相邻 bond_edge_map 必须在最终有效图上重建并验证每个 (i,i+1) 恰好存在；预测头继续用原相邻 e0，不因为候选全图行序变化而串位。全局边的 type=4、distance=0 和原边属性完全保持。

必要 pod 预检：固定 mask 的 carrier 与原图传播在合理数值容差内相同；每条序列恰好 M(L) 非主链对且成双向；主链/全局边完整、无重复、无跨样本边；padding 扰动不改变输出；train/eval hard-selection 一致；selector 和 gate 梯度有限且非零；所有排序/分数有限；更换标签但固定输入不会改变构图；不读取测试标签、谱峰目标、q 或四状态 target 构图。

报告新增：d≥6 边比例、与位置图的 Jaccard、距离/度分布、随输入条件的连接变化、训练/验证/测试边选择分布、实际耗时/显存。学习出的边是预测相关性通路，不能解释为真实三维接触、静电作用或化学断裂路径。

## 共同报告和结论边界

每组分别完成、报告，再进入下一组，不与宽度批次并行。固定相同五个重叠划分、相同随机种子/训练策略/内部完整谱图验证/去 padding 指标。每组重新训练同轮对照，不拿不同批次的最佳外层测试数值代替同轮对照。输出 Bond-F1、accuracy、AUC、谱图平均 P/R 的调和 F1、q-Brier、q_seq 的逐划分值、均值、标准差、成对差值、胜率，以及参数量和耗时。沿用已冻结工程门槛并同时报告所有候选，不能在测试集挑完赢家再把赢家当确认性最优。

动态边 D 优于 S0 却不优于 S1：只能说边侧容量/上下文编码有用。G2 优于 G0 却不优于 G1：只能说成对门控有用，不能说新增长程连接有效。负结果只说明这一特定实现/训练预算未获益；可能是现有全局节点已提供短路径、上游节点表征没有识别有用长程关系的线索、优化不足、小独立序列量下过拟合、理论晚融合未向上游提供条件，或新连接噪声较强。若早融合改进而动态图不改进，应先判断上游信息条件，但不能仅凭几组消融定论。

保存每组 source commit、配置、manifest/hash、五划分 checkpoint 和恢复说明。提升版本登记为候选，需复验后才替换稳定最佳引用；原成功四状态代码和权重引用始终保留。
