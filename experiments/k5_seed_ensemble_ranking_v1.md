# 单全局节点 k=5 四状态模型：同折多训练种子排序探索

授权：2026-10-25 用户要求停止叠加虚拟节点，继续探索当前主模型的序列排序。此项只平均已有单节点 k=5 四状态模型的预测，不训练新架构，不选择外部测试表现最好的种子或权重。

## 冻结比较

- 固定三份独立训练来源：stage11 `single`（训练 base seed 42）、stage8 `single_k5`（43）、stage10 `single`（45）。每个来源只使用对应外部划分的 checkpoint；五划分为 1222、2252、3514、6072、9075。绝不跨划分集成。
- 三模型的隐藏维 256、四状态头 alpha=1/Brier=0、单全局节点、NodeEncoder 后单尺度 Conv1D k=5、原 concat/late/static/nocharge、3 GCN + 2 GAT、4 heads 均须逐份核验。各 checkpoint 原先仅按本划分内部验证 F1 选取，内部划分 base seed 42、外部序列测试源相同。若模式、数据、目标或权重 SHA 不匹配，停止分析。
- 预先固定算术平均：逐谱图、逐有效肽键对三个模型输出的可观测断裂概率 `q=1−P(none)` 等权平均；阈值固定 0.5。对完整测试源同次重放推理，不依赖历史六位小数预测文件；padding 位置排除。与三个单模型、预指定 seed42 单模型及三份单模型指标的算术平均并列，不逐折挑赢家。
- 排序双指标：唯一序列级 q_seq Spearman 和 Top10 富集。其他报告：肽键 F1、accuracy、AUC、谱图平均 precision/recall 及调和 F1、q-Brier。每个来源和集成报五划分均值、样本 SD、逐划分值；集成减 seed42 以及集成减三单模型平均报配对差均值、SD 和方向。额外记录推理成本约为单模型三倍、参数总量及权重路径。
- 探索性保留标准：q_seq 和 Top10 相对 seed42 均值同向提高，且两项各至少 4/5 划分提高；同时肽键 F1 不下降超过 0.2 个百分点、AUC 不下降超过 0.001、q-Brier 不增加超过 0.001。标准只指导后续研究优先级，不是显著性检验；所有实际结果照报。

## 来源与审计

本机只编辑协议/代码、同步、查看小报告。所有数值处理、模型恢复、推理、复算和绘图在已授权 pod `gsj-5090.devpod` 上执行。pod 端独立保存训练源码修订、三份历史 registry SHA、15 份配置/权重 SHA、测试源及标签 SHA、严格 CPU checkpoint 恢复记录，并检查实际训练/划分种子、模型模式和参数数目。逐谱图同次预测与原 CSV 的序列、条件、硬软标签逐行对齐；独立从有效键概率重算全部指标。结果写入独立 ops 目录，含 JSON、中文报告和可查看的 HTML/图。旧结果及冻结论文主表保持不动。

此前五个外部序列划分彼此重叠，且已经多轮用于结构选择。这是多种子推理的探索性同轮对照，不构成论文确认性性能证明。即使有收益，也需冻结规则，在此前未用于选型的序列隔离数据上与单节点单模型及论文关键基线同批评估，并报告配对不确定性。
