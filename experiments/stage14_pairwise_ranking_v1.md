# Stage 14: training-only pairwise ranking auxiliary loss

This is an independent same-round four-arm ablation on the original single-global-node, single-scale Conv1D `k=5`, H256, 3GCN+2GAT, FiLM, late/static/concat/nocharge, four-state α=1/Brier=0 model. The four arms differ only in `loss.ranking_loss_weight`: `0`, `0.01`, `0.05`, `0.10`. Every arm uses `loss.ranking_loss_mode=pairwise_logistic`, temperature `0.1`, target gap strictly greater than `0.05`, the original random row sampler, training base seed 42 and internal validation split base seed 42. Lambda zero computes pair-availability diagnostics but contributes exactly zero ranking gradient. It is the required fair control.

The existing `Trainer._sequence_ranking_loss` is a historical batch-local **hinge** loss with a `ranking_margin` parameter. It previously yielded a negative result. This study leaves that code and its default route intact. The new optional logistic route is a different loss. The existing peptide auxiliary-head RankNet loss is also distinct: Stage 14 directly constrains the four-state union prediction, adds no head, and changes no inference parameters.

Four-state output `[none,b,y,both]` maps to a union bond probability `q=1−P(none)` via the existing `union_logit` model output. For each folded outer-training condition row, the training objective averages `sigmoid(union_logit)` and `soft_multi` over valid bonds. It averages repeated rows within each `(sequence,charge,NCE)` condition, then gives conditions equal weight within each sequence. A minibatch forms only unordered **different-sequence** pairs with absolute mean target gap `>0.05`, applying `softplus(−sign(Δtarget)·Δprediction/0.1)`. No external test label, q or score enters training; the fold's outer-train-only q source and sequence-disjoint internal split are SHA-bound to the reviewed Stage 11 evidence during pod smoke. The existing random row sampler means minibatches may contain only a subset of a sequence's conditions. This is a stochastic proxy for the full `q_spearman_pep_seq` metric, whose evaluation groups all conditions first, then sequences. Batch legal-pair count, zero-pair count, raw rank loss and weighted output-gradient magnitude are recorded for every epoch. The exact full-sequence metric is recomputed from predictions only after training.

All four arms use original sequence-grouped external folds `1222,2252,3514,6072,9075`, group-uniform folded training, complete original-spectrum internal validation, `max_f1` checkpoint selection, and fixed threshold 0.5 with all valid-bond metrics padding-free. No epoch, threshold, λ, τ, δ or seed is chosen using external test data. The pod-only ops path is `/mnt/pvc/graphtrans/dbond_s14_pairwise_ranking_20261026_ops`; its run root is under `/mnt/pvc/graphtrans/DBond/checkpoints/graph_transform/stage14_pairwise_batch/<timestamp>`. `smoke` must pass once before `launch`. `worker` creates `terminal.json` only after all 20 fold runs and an `audit_manifest.json` containing actual arm/fold/seed/λ/τ/δ/max sequence length, source commit, train/validation/test/prediction/metric/checkpoint/config paths and SHA256s. Independent pod audit still must strictly restore all 20 checkpoints, verify same-pass prediction provenance and recompute all metrics before any scientific interpretation or acknowledgment.

Primary comparison is each positive λ against same-round λ=0. Predeclared screening gates: mean `q_seq` improvement ≥0.01 with ≥4/5 fold wins; mean Top10 enrichment improvement ≥0.01; Bond-F1 degradation no worse than 0.20 percentage points, spectrum-F1 degradation no worse than 0.20 percentage points, and q-Brier degradation no worse than 0.001. All arms and metrics, paired fold differences, SDs, time, memory and parameters must be reported. Five overlapping folds and one initialization are exploratory evidence, not five independent replications. Failed smoke, source binding or run is a halt; no automatic retry or model promotion.

This local implementation is **not** pod-validated or launched. It is an isolated snapshot for parent review and integration. All numerical work, training, metric recalculation and plotting are reserved for the authorized pod.
