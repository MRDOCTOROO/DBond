# 原主干完整保留＋并行8头邻域Q/K/V分支（2026-10-28）

用户授权：保留原来的特征提取，再把8头交叉注意力作为并行分支融合，做一组对照，看能否保住F1同时提升排序能力。

## 唯一候选：parallel_qkv8

原单模型全部保留：H256 NodeEncoder、单尺度k5、单全局节点、FiLM、3层GCN、2层原4头加性GAT、15维理论特征、原concat四状态头α=1/Brier项=0。

```text
NodeEncoder → k5 → 单全局节点打包/FiLM → 3GCN → H3
                                                 ├→ 原GAT4 → 原GAT4 → H5 ─────┐
                                                 └→ 新8头邻域Q/K/V → Wo(context)┤
                                                                              ↓ 相加
                                                      原肽键特征拼接与四状态头
```

并行分支只有1个8头邻域注意力模块，读取与原第一层GAT相同的H3。没有替换、删除、复制或改造原GAT。
Q由中心节点H3产生，K/V由原图入邻居H3产生，每个头都从完整256维表示投影到32维；保留同一静态图、原单全局双向边、边偏置和边消息门控。

对j→i、头a：

- q_i^a=Wq^a H3_i，k_j^a=Wk^a H3_j，v_j^a=Wv^a H3_j。
- s_ji^a=(q_i^a·k_j^a)/sqrt(32)+b_a(e_ji)，alpha在中心i的入邻域按头softmax。
- c_i^a=sum_j alpha_ji^a·[sigmoid(G_a(e_ji))⊙v_j^a]。
- H_fused_i=H5_i+Wo concat_a(c_i^a)。Wo的weight和bias均零初始化。

空入邻域的分支更新为0。新分支不加残差、LayerNorm、dropout、FFN或任意缩放系数；唯一残差在与原H5融合处。
新分支在所有历史初始化之后fork_rng构造，原主干初始权重及后续随机流不变；初始预测和四状态logits必须与原模型CPU精确相同。初始等价并不保证训练后F1不下降。
只在有效节点打包后计算，不添加padding节点、新边、跨肽链边、额外虚拟节点或真实3D接触假设。
