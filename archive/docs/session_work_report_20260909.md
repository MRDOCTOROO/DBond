（五折 5-seed 集成为最高置信杠杆）。

## 2. 完成的工作

### 2.1 q 口径补评体系修复

- **事故一**：q 消融补评命令把评估放到了不存在的 GPU 5（机器仅 0-4 卡）→ auto_detect
  回退 CPU，4.2s/batch。修正为真实卡号。
- **事故二（实质性问题）**：`pre_synthesis_5fold_md6.yaml` 无 `use_soft_labels` 键（默认
  False），评估批次不携带 soft_labels → 无理论臂补评**全部 q_* 指标缺失**。修复：新增
  `graph_transform/config/pre_synthesis_5fold_md6_qeval.yaml`（= md6 配置 +
  `use_soft_labels: true`，仅评估用，不用于训练），重跑五折补评。
- **事故三（metrics 模块陷阱，已记录）**：`BinaryBondMetrics.compute()` 内部固定按 logits
  过 sigmoid（`training/metrics.py` 的 `from_logits` 只在 update 侧生效），直接喂概率会被
  双 sigmoid → 全预测正（f1 恰好掉到 2·π/(1+π)=0.642）。离线补评工具以 logit 逆变换
  规避（与 `ensemble_inference.py` 同一做法）。

### 2.8 FiLM 单变量归因（解释 + 实证）

机制：charge/NCE → MLP(2→64→512) → (γ,β)，节点表示 `x·(1+γ)+β`，作用于节点打包后、
消息传递前（graph_transformer.py:665-675）；零初始化恒等起步（无风险），3.3 万参数。
五折单变量对照（同底座 ±use_condition_film）：

| 指标 | uniform（无 FiLM） | +FiLM |
|---|---|---|
| lab_F1 (%) | 79.54±0.73 | **79.80±0.64**（家族最高） |
| q_brier ↓ | 6.83 | 6.69 |
| q_pep / cond | 89.39 / 88.75 | 89.67 / 89.01 |
| q_seq | 61.71±2.47 | 62.52±5.93 |

净效果：**折叠本身让 q_pep/cond 掉 ~0.5 点，FiLM 拿回约一半，同时 F1 超过未折叠硬标签臂
（79.80 vs 79.50）**——"折叠的训练效率（50×）+ 不输硬标签的质量 + F1 新高"三者兼得。
注意 q_seq 方差翻倍（2.5→5.9），非逐折稳健的赢。

### 2.9 概念澄清（会话内问答，供论文写作引用）

- **q / q 软标签 / q 预测**：q = 条件组 (seq,charge,NCE) 内逐键平均断裂率（期望行为真值）；
  单谱 0/1 是其含噪一次实现（同条件不一致率 14.91%）。q 软标签 = 把 q 当训练目标（折叠后
  每组一行，其正确目标即 q；重复行版与硬标签数学等价，见 §7.2 定理）或评估真值（test 折
  soft_multi，无泄漏）。q 预测 = 把模型逐键概率 p 当作对 q 的回归估计来评估（模型不变）。
- **q_* 指标含义**：q_brier/q_mae/q_rmse=校准误差；(q_)pearson/spearman=键级相关；
  q_spearman_pep=肽级排序（行/cond 去重/seq 每序列一票三口径）；q_ndcg（近饱和 0.992，
  区分度弱）；q_top10/20_enrichment=前 K% 的真实 q 均值/总体均值（>1 富集）。
- **训练速度来源与精度影响**：条件组折叠（383,295 行 → 7,643 组，~50×）在 spectrum 加权下
  数学无损（实证同折 79.51 vs 79.08）；group_uniform 微代价（q_pep/cond −0.5 点）由 FiLM
  买回；F1 全程不降。速度不是用精度换的。
- **主模型配置卡**：3GCN+2GAT 混合骨干 + 15 维理论特征 + 条件折叠(group_uniform) + q 软标签
  + FiLM；输入=序列/charge/pep_mass/NCE（intensity/scan_num/rt 屏蔽）；双 checkpoint
  （best_model.pt 分类 / best_model_q.pt 排序）；可选 5-seed 概率平均。
- **特征对比**：五模型可观测量完全同源（seq/charge/mass/nce）；GT 多派生表示（理论特征、
  理化/位置嵌入、图边、FiLM），全部合成前可计算，无质谱后信息；严格同特征对照用
  dbond_*_pre_theory 变体。

### 2.10 数据完整性对账（回应"是否压缩/遗漏"）

逐折实点（pod）：train+test 行数逐折精确 = **477,669**（=原始全部谱图）；五折累计唯一序列
= **513**（=全库）；**划分按序列不重叠**（每折 train 410-412 条 / test 101-103 条，交集 0）；
7,643±60 = train 侧 (seq,charge,nce) 条件组数；test ~1,900 组。折叠只作用于训练侧且无损
（行数守恒断言内置）。更正表述：不是"只有 410 条序列"，而是"**每折训练可见 ~410 条，
需泛化到 ~103 条零重叠的全新序列**"——q_seq 的 0.62-0.65 量级与高方差由此决定。
另：`name` 是肽名非谱图唯一标识（谱图需 name+scan_num+rt 联合定位），审计时勿混淆。

## 4. 难点与痛点

1. **realized 噪声地板**：同条件 14.91% 不一致 → 行级天花板 0.888；pre 全模型挤在 79-80，
   行级指标无法区分模型优劣，审稿说服力必须靠 q 口径补充。
2. **序列库太小**：全库 513 条、每折训练 ~410 条、测试 ~103 条零重叠新序列——q_seq 方差
   大（GT std 5.9）、模型间差异不稳定，单折试点两次假阳性（教训：q_seq 只认五折）。
3. **容量-泛化权衡**：GT 容量大 → 条件结构拟合好（行级/校准强）但序列级泛化弱于强正则的
   dbond_s（62.5 vs 65.1）；"全指标最优"需同时打败两类极端，难度本质在此。
4. **pre 设置无模型全面占优**：论文叙事只能写"分层领先"（GT=obs 全面优势 + pre 行级/校准
   第一梯队；af=排序最强；dbond_s=最稳序列排序器），需如实呈现。
5. **工程坑**：metrics 模块 from_logits 不一致（双 sigmoid 陷阱）；评估侧软标签开关决定
   q 指标可见性；DevPod 代理 ssh 尾部报错噪音；`name` 非谱图唯一键。
6. **未量化项**：global node（虚拟节点）无单独消融；max_distance 仅 md3/md6 对照
   （0.7921 vs 0.7940）；long_range 边从未打开。
7. **集成成本**：5-seed 概率平均推理成本 ×5；"DBond-GT (ensemble)" 口径需如实标注。

## 5. 推测与假设（按置信度排序）

1. **【高，有单折实证】五折全量 5-seed 集成可将 GT 推到"每列前二"并反超 dbond_s 的 q_seq**
   （fold-1222 实测 +5.7；若全折同幅度，q_seq ~67 vs dbond_s 65.1，Brier/MAE 大概率超
   af_opt，F1 ~80.4）。成本 ~2.5 小时（折叠训练便宜）。这是让"GT 全指标较优"的最高置信路径。
2. **【中高】dbond_s 的序列级优势源于架构级强正则**（逐键独立、容量小）；GT 用方差缩减
   （集成/正则）可逼近，用结构模仿（缩小模型）可能两头落空。
3. **【中】正则化上调（dropout 0.1→0.2/0.3、weight_decay ×5）直接对症 GT 的序列级方差**，
   F1 或微降，需两档试点。
4. **【中】条件 dropout**（训练时随机屏蔽 charge/nce，p≈0.2）可阻止条件过拟合、逼序列级
   泛化；与 FiLM 正交（FiLM 用条件、dropout 强迫不完全依赖），实现便宜。
5. **【中低】图结构微调（md4/md8、long_range on、global node off 对照）收益有限**
   （肽短，md6 已近稠密；虚拟节点大概率小幅正收益但未量化）——值得便宜试点，不押注。
6. **【结构判断】obs 设置下 GT 的 q 口径大概率同步全面领先**（realized 全列第一 + 特征信息
   量优势）；若论文需要"GT 赢面"的 q 表，可对 obs 系列做同管道补评（工具现成）。
7. **【长期】扩候选序列库是 q_seq 的根本解**：410→数千条时所有模型 q_seq 上行，GT 的容量
   优势反而更可能兑现。
8. **【已证伪，勿再投入】**：软标签重加权（≡BCE）、序列级 ranking loss、FiLM+辅助头叠加、
   ASL、收缩估计——目标侧已饱和；跨折模型混用（协议无效）。
