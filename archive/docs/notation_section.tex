\subsection{符号定义与消息传递约定}
\label{sec:notation}

为统一后续图神经网络公式的描述，首先定义相关符号与约定。
图构建阶段（见第~\ref{sec:graph_construction}~节）采用无向图表示残基之间的拓扑关系；
为兼容消息传递框架，每条无向边 $(v_i,v_j)$ 在计算时展开为两条方向相反的有向边
$(v_i\rightarrow v_j)$ 与 $(v_j\rightarrow v_i)$，因此后续所有公式均基于对称化后的有向图定义。

记 $\mathcal{N}(j)=\big\{\,v_i\,\big|\,(v_i,v_j)\in\mathcal{E}\,\big\}$ 为节点 $v_j$
的入邻居集合，即所有指向 $v_j$ 的源节点集合。若启用全局虚拟节点 $v_g$，
则其与各残基节点的连接边同样计入相应节点的邻居集合与度中。

节点 $v_i$ 的度定义为 $\hat{d}_i=\big|\mathcal{N}(i)\big|$，
按最终用于消息传播的图（即在加入全局节点及其连接之后）统计得到。
